SQLite 复现库缩减服务

上传结构受限的 SQLite 库与确定性 SQL 脚本，确认原始错误后自动删除数据行， 生成“再删任一行及其外键闭包就无法复现”的最小复现库。 另有“迁移取数核查”：调整库结构前，验证下游取数 SQL 不丢行、不改值。

输入约束

  • 至多 3 张普通表，无触发器、无视图、无虚拟表；全部表共至多 60 行。
  • 主键与外键均为 单列 INTEGER，外键必须引用目标表主键，允许循环引用。
  • 上传库现有数据必须已满足外键约束；脚本不得访问外部文件（ATTACH/PRAGMA/扩展等被拦截）。
  • 复现判定：SQLite 扩展错误码 与完整错误文本完全一致；其它错误不算复现。
  • 每次试跑使用独立副本，先 COMMIT 再失败也不会污染原件、后续试跑或下载库。

迁移取数核查

调整故障样本库结构前，确认下游取数 SQL 不丢行、不改值： 上传符合原有约束的 SQLite 库、不得访问外部文件的迁移 SQL，以及 1～3 条 确定性只读 SELECT。服务在独立副本上执行迁移（脚本须完整成功），关闭连接后 按实际已提交的数据校验目标库结构与外键，再逐条比对两侧查询结果的 列名、每个值的 SQLite 类型与内容、重复行次数（忽略行顺序）。 查询超过 200 行或试跑时限不予放行；全部一致才可下载升级库。
